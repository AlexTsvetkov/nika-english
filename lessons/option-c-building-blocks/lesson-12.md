# Lesson 12 — our new pattern: "How many ___? — numbers 1 to 20"

Today Nika counts and asks **How many ___?** (сколько ___?) and answers with numbers up to twenty.

## 📋 Plan
1. **Flashback review** (4 min) — plurals from Lesson 11: one cat / three cats, These are ___.
2. Meet our pattern (6 min) — count 1–20, then ask "How many?" and answer. Read the table.
3. Drill + count (10 min) — do the exercises below.
4. Say it about YOU (5 min) — Nika counts her real things.

## 🎯 What we will learn
- Our new pattern: **How many ___? — There are ___** + numbers 1–20.
- Words: how many 🔢 (сколько), ten 🔟 (десять), twenty (двадцать), fingers ✋ (пальцы), apples 🍎 (яблоки).

## ✏️ Exercises for Nika

**1. Substitution table — read each row aloud:**

| How many | cats? | There are | three cats |
| How many | books? | There are | ten books |
| How many | apples? | There are | twenty apples |

**2. Fix the sentence** — this one is broken, fix it:
- "How many cat?" → say it the right way (many things take the *-s*: How many cats?).

**3. Fast swap** — parent says Russian, Nika says English, then back:
- сколько книг → how many books … there are five → there are five … двадцать → twenty

**4. Matching game** — match the number word to the digit:
- seven, twelve, fifteen, twenty  →  12 / 20 / 7 / 15

**5. Say it about YOU** — parent asks, Nika counts for real:
- How many fingers? → There are ten. / How many pens? → There are ___ .

## 🏠 Homework
Every day (5 min): count to twenty aloud, then count real things — "How many ___? There are ___."

> 🇷🇺 Thirteen–nineteen end in *-teen* (say the TEEN); twenty is different. Count on fingers so the sound and the number stick together.
