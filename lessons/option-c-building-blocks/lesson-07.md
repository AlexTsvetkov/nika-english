# Lesson 7 — our new pattern: "I / You / We + action word"

Today Nika says what she does: **I play / You run / We go** (я играю / ты бегаешь / мы идём).

## 📋 Plan
1. **Flashback review** (4 min) — am/is/are chart + I have / I like.
2. Meet our pattern (6 min) — read the table together, point at each word.
3. Drill + swap (10 min) — do the exercises below.
4. Say it about YOU (5 min) — Nika says real actions.

## 🎯 What we will learn
- Our new pattern: **I / You / We + action word** (play, run, go...)
- Words: play ⚽ (играю), run 🏃 (бегаю), go 🚶 (иду), eat 🍽️ (ем), read 📖 (читаю).

## ✏️ Exercises for Nika

**1. Substitution table — read each row aloud, swapping the action word:**

| I | play |
| You | run |
| We | go |
| I | eat |

**2. Fix the sentence** — this one is broken, fix it:
- "I plays." → say it the right way (with I, the action word stays plain — no *s*).

**3. Fast swap** — parent says Russian, Nika says English, then back:
- я бегаю → I run … we read → мы читаем … you eat → ты ешь

**4. Matching game** — match the action to its meaning:
- play • run • eat • read  ↔  читаю • играю • ем • бегаю

**5. Say it about YOU** — Nika makes 3 true sentences:
- I play. / I read. / We eat.

## 🏠 Homework
Every day (5 min): say 5 "I ___" action sentences about your real day.

> 🇷🇺 Good news: with *I / you / we* the action word stays plain — nothing to add. Russian changes the verb a lot; here it is easy. (Careful next time: he and she will be different!)
