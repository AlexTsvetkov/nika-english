# Lesson 6 — our new pattern: "I have ___ / I like ___"

Today Nika's first doing-words: **I have ___ / I like ___** (у меня есть ___ / я люблю ___).

## 📋 Plan
1. **Flashback review** (4 min) — the whole am/is/are chart from last time.
2. Meet our pattern (6 min) — read the table together, point at each word.
3. Drill + swap (10 min) — do the exercises below.
4. Say it about YOU (5 min) — Nika says what she has and likes.

## 🎯 What we will learn
- Our new pattern: **I have ___ / I like ___**
- Words: have (имею), like (люблю), dog 🐕 (собака), ball 🏀 (мяч), cats 🐈 (кошки), ice cream 🍦 (мороженое).

## ✏️ Exercises for Nika

**1. Substitution table — read each row aloud, swapping the last word:**

| I | have | a dog |
| I | have | a ball |
| I | like | cats |
| I | like | ice cream |

**2. Fix the sentence** — this one is broken, fix it:
- "I have dog." → say it the right way (add the little word *a*).

**3. Fast swap** — parent says Russian, Nika says English, then back:
- у меня есть собака → I have a dog … I like ice cream → я люблю мороженое

**4. Matching game** — match the word to its meaning:
- have • like • dog • cats  ↔  собака • кошки • имею • люблю

**5. Say it about YOU** — Nika makes 3 true sentences:
- I have a ___. / I like ___. / I have a ___.

## 🏠 Homework
Every day (5 min): say 3 true "I have ___" sentences and 3 true "I like ___" sentences.

> 🇷🇺 Russian says "у меня есть собака" (literally "by me there is a dog"). English is simpler: **I have a dog** — person first, then the word. Keep the little *a*.
