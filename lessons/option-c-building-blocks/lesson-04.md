# Lesson 4 — our new pattern: "It is a ___ / This is a ___"

Today Nika points at things: **It is a ___ / This is a ___** (это ___).

## 📋 Plan
1. **Flashback review** (3 min) — our old patterns: I am ___, You are ___, He/She is ___.
2. Meet our pattern (6 min) — read the table together, point at each word.
3. Drill + swap (11 min) — do the exercises below.
4. Say it about YOU (5 min) — Nika points at real things.

## 🎯 What we will learn
- Our new pattern: **It is a ___ / This is a ___**
- Words: it (оно), this (это), cat 🐈 (кошка), ball 🏀 (мяч), book 📘 (книга), dog 🐕 (собака).

## ✏️ Exercises for Nika

**1. Substitution table — read each row aloud, swapping the last word:**

| It | is | a cat |
| It | is | a ball |
| This | is | a book |
| This | is | a dog |

**2. Fix the sentence** — this one is broken, fix it:
- "It is cat." → say it the right way (add the little word *a*).

**3. Fast swap** — parent says Russian, Nika says English, then back:
- это кошка → this is a cat … a ball → мяч … this is a book → это книга

**4. Matching game** — match the word to its meaning:
- cat • ball • book  ↔  книга • мяч • кошка

**5. Say it about YOU** — Nika points at 3 real things in the room:
- This is a book. / This is a ball. / This is a cat.

## 🏠 Homework
Every day (5 min): walk around home and point — This is a ___ (name 5 things).

> 🇷🇺 English puts a little word **a** before a thing (a cat, a ball). Russian has no articles, so it is easy to forget — always add *a*.
