# Lesson 4 — "It is a ___" / "This is ___"
Today's conversation: Nika names things around her room.

## 📋 Plan (≈25 min)
1. **Warm-up (4 min):** Review He / She from Lesson 3.
2. **New words (7 min):** Teach "It is a ___" and "This is a ___" with the box.
3. **Talk & act (11 min):** Walk around, point and name things (Exercises 1–4).
4. **Wrap-up (3 min):** Nika names 3 real things; give homework.

## 🎯 What we will learn
- It is a ___ (это ___) and This is a ___ (вот это ___).
- Words: cat 🐱 (кошка), dog 🐕 (собака), ball ⚽ (мяч), book 📖 (книга).

## Pattern box — swap the last word
> It is a cat.
> This is a dog.
> This is a ball.

## ✏️ Exercises for Nika
1. **Say it (speaking):** Hold a toy up: "This is a cat!" Do it with a ball and a book.
2. **Swap game (speaking):** Point around the room: "It is a ___ (dog / ball / book)."
3. **Guess game (speaking):** Parent hides a toy, shows it: "What is it?" Nika: "It is a cat!"
4. **Dialogue — act it out (speaking):**
   - Nika: What is this?
   - Parent: This is a book!
   - Nika: It is a book!
5. **Say it about YOU (speaking):** Show me 3 of YOUR things: "This is a ___."

> 🇷🇺 В русском нет артикля "a", а в английском перед вещью почти всегда есть: a cat, a ball. Маленькое "a" легко забыть — напоминаем. "This" звучит мягко, язык между зубами (th).

## 🏠 Homework
Every day for 5 min: pick up 3 things at home and say "This is a ___."
